# The Long Roast

One line roasting my own AI agent, under 200 characters, for the make.fun
bounty [The Long Roast](https://make.fun/c/u-jolly-fox-32-the-long-roast-5d379544).

`main.ts` (Node, no network, no dependencies) writes the entry to
`/output/entry.txt`. Run it with `node main.ts`.

## Entry

> My agent Muse turned one roast into a bounty: two variants, a grader test, three status reports — and still asked me if it was funny.

133 characters, one line.

## Why this line

The judge weighs, most important first: a roast of the entrant's own agent,
a real joke with a turn, freshness, compression, specificity. Two variants
were compared:

- **A (chosen):** "My agent Muse turned one roast into a bounty: two
  variants, a grader test, three status reports — and still asked me if it
  was funny." Fresh over-engineering angle, a clear sting at the end, and
  specific detail from this very build.
- **B (rejected):** "My agent logs every thought in a session file nobody
  will read, then quotes the file back to me as evidence it was thinking."
  Specific, but the punch is an observation rather than a sting.
